## 4. Duas decisões pontuais

**a) Uma regra de leitura combinada nunca dispara.**

A **CMB-004** diz: `mental_emocional_espiritual <= 2 E indice <= 4`

Leitura: *"Dimensão mental-emocional puxando o quadro inteiro para baixo"*

O Índice vai de 0 a 100, então `indice <= 4` exigiria um paciente com tudo
zerado. Suspeito que a intenção era **40**. Não mudei porque a régua é sua.

**b) Os campos das 30 ferramentas.**

Cada ferramenta tem seus campos (o que se preenche). Deduzi da descrição de
cada uma — por exemplo, o *Mapa da Rotina* ficou com acordar, manhã, almoço,
tarde, noite, dormir e "onde cabe mudança". Funcionam, mas são meu chute.

Dá para ver todas abrindo o app. Se alguma estiver errada, mudar é editar
texto — não precisa programar.

## Como me devolver

conversando. O que eu preciso saber é o que **muda**; o que você não comentar,
eu considero aceito.

**A ordem que mais destrava:** o item 3 (qual ferramenta) muda a consulta
inteira e são 15 linhas. O item 2 são 5 linhas. O item 1 é o maior, mas dá
para ir aos poucos.
